# Bun Migration + Full Toolchain Update

**Date:** 2026-04-13
**Branch:** feature/move-to-action-pattern

## Overview

Migrate the frontend from npm/yarn to bun, and perform full major-version upgrades of dev tooling: ESLint 7→9 (with flat config), husky 4→9, lint-staged 11→15. Remove unused webpack-era dependency (`resolve-url-loader`). Update `sass` to latest minor.

---

## 1. Bun Migration

**Changes to `package.json`:**
- Add `"packageManager": "bun@1.x"` field
- Update `scripts.lint` and `scripts.lint-fix`: replace `./node_modules/.bin/eslint` with `eslint` (bun resolves binaries automatically)
- Remove `husky.hooks` config (moved to `.husky/` directory in husky v9)

**Changes to `.gitignore`:**
- Add `bun-error.log`
- Keep `yarn-error.log` (already present)

**Lock file:**
- Delete `package-lock.json`
- Commit `bun.lockb` (generated by `bun install`)

---

## 2. ESLint 7→9 (flat config)

**Remove from `devDependencies`:**
- `@babel/core`
- `@babel/eslint-parser`

**Update in `devDependencies`:**
- `eslint`: `^7.20.0` → `^9.0.0`
- `eslint-plugin-vue`: `^7.6.0` → `^9.0.0`

**Add to `devDependencies`:**
- `@eslint/js`: `^9.0.0` (official base rules for flat config)

**Delete:** `.eslintrc.js`

**Create:** `eslint.config.mjs` (`.mjs` extension required because `package.json` has no `"type": "module"`) with the following rules ported from `.eslintrc.js`:

```js
// eslint.config.mjs
import js from '@eslint/js'
import pluginVue from 'eslint-plugin-vue'

export default [
  js.configs.recommended,
  ...pluginVue.configs['flat/vue3-recommended'],
  {
    rules: {
      'indent': ['warn', 4],
      'vue/html-indent': ['warn', 4],
      'jsx-quotes': ['error', 'prefer-double'],
      'linebreak-style': ['error', 'unix'],
      'quotes': ['warn', 'single'],
      'semi': ['warn', 'never'],
      'vue/sort-keys': 'off',
      'vue/static-class-names-order': 'off',
      'vue/no-v-html': 'off',
      'vue/require-valid-default-prop': 'off',
      'vue/require-explicit-emits': 'off',
      'vue/no-multiple-template-root': 'off',
    },
  },
]
```

**Update `scripts.lint` and `scripts.lint-fix`:**
- Remove `--ext .js,.vue` (flat config handles extensions via file patterns)
- Remove `-c .eslintrc.js` (flat config is auto-discovered as `eslint.config.js`)
- Remove `--ignore-path .gitignore` (flat config uses `ignores` array or `.eslintignore` is deprecated; add `ignores` to `eslint.config.js` if needed)

Updated scripts:
```json
"lint": "eslint resources/js --max-warnings=0",
"lint-fix": "eslint resources/js --fix --max-warnings=0"
```

## 3. Husky 4→9

**Remove from `package.json`:**
```json
"husky": {
  "hooks": {
    "pre-commit": "lint-staged"
  }
}
```

**Update `devDependencies`:**
- `husky`: `4` → `^9.0.0`

**Create** `.husky/pre-commit` (must be executable: `chmod +x .husky/pre-commit`):
```sh
bunx lint-staged
```

**Setup:** Run `bunx husky init` after install, then replace content with `bunx lint-staged`.
